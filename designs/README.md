# SmartAudit Design Repository

## Adding New Designs

1. Create a folder in the correct category.

Example:

```text
components/audit-table/
```

2. Add:

```text
README.md
preview.png
figma-link.txt
assets/
```

3. Submit PR.

---

## Naming Convention

Use kebab-case.

Good:

audit-table
dashboard-overview

Bad:

AuditTable
dashboard_v2_final
New Folder
